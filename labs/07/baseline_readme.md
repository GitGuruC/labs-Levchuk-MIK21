# Baseline: Поиск музыкальных ассетов по текстовому описанию

## Команды запуска

Все команды выполняются из директории `labs/07` (требуется Python 3.10+, внешние библиотеки не требуются):

```bash
# 1. Полное воспроизведение датасета, расчёт метрик на validation и сохранение артефактов
python src/baseline_search.py run

# 2. Интерактивная проверка на буквальном запросе (лексика из словаря train)
python src/baseline_search.py search --query "мрачный синтезатор бас"

# 3. Интерактивная проверка на синонимическом запросе (сленг монтажёров)
python src/baseline_search.py search --query "тягучий подклад хоррор"
