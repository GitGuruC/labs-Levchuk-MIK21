# Лабораторная работа 8: Метрики и анализ ошибок

Спецификация метрик, ручная верификация расчётов, таксономия ошибок и гипотеза для следующего шага по проекту поиска музыкальных ассетов (продолжение ЛР 7).

## Файлы работы

* `metric_spec.md` — спецификация основной (`NDCG@3`) и защитных метрик, пороги принятия Alpha-версии.
* `manual_calculation.md` — пошаговый ручной расчёт `NDCG@3` и `Recall@3` для идеального, неполного, инвертированного и пустого списков.
* `error_taxonomy.md` — разбивка результатов baseline по сегментам и жанрам, таксономия ошибок и связь с требованиями ЛР 3.
* `hypothesis.md` — карточка проверяемой гипотезы `H1` для ЛР 9.
* `verify_metrics.py` — скрипт сверки ручных расчётов с кодом ЛР 7 и запуска граничных тестов.

python verify_metrics.py
